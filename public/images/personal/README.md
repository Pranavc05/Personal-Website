# Personal photos

1. Add image files here:
   - `portrait.jpg`
   - `campus.jpg`
   - `huskies.jpg`
   - `basketball.jpg`

2. Enable them in `src/data/personalPhotos.ts` by setting the matching path, e.g.:

```ts
portrait: '/images/personal/portrait.jpg',
```

Until a path is set, the UI shows a cream placeholder and does not request a missing file.
